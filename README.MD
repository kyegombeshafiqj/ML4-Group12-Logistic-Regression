# Machine Learning 4 – Logistic Regression from Scratch

## Group 12

Implementation of a multivariable logistic regression model from scratch in C++.

## Project Scope

The project covers:

- Dataset loading
- Data preprocessing
- Multivariable logistic regression
- Log-odds
- R-squared
- P-value
- Train/test split
- Prediction
- Confusion matrix
- Precision
- Recall
- F1-score

C++
