## 1. Project Understanding

Our group was assigned to implement Logistic Regression from
scratch in C++.

The main components of the project are:

- Dataset loading
- Data preprocessing
- Multivariable logistic regression
- Log-odds
- R-squared
- P-value
- Train/test splitting
- Prediction
- Confusion matrix
- Precision, Recall and F1-score

The implementation will be developed in C++ without relying on a
ready-made logistic regression model.
